# Index

**[RESULTS.md](RESULTS.md) is the record and the authority. This file is a map of
it.** It carries no reading of its own: every row below is one section heading of
the ledger, linked to that section, and the table is generated by
`scripts/make_index.py`, so a block cannot be in the ledger and missing here.

[README.md](README.md) is the entry point and says what the programme claims.
This file says where each piece of it is.

## Lines to read in order

**The station numbers are stable identifiers rather than a reading order.** A
line below is a route through the ledger; the table after it is the whole thing,
sorted by number. A station can sit on more than one line, and a line naming
fewer stations than belong on it is an incomplete map rather than a claim that
the rest are not there.

**A price is not a scalar field on positions.** The rival is one scalar per position whose gradient generates every term, so every closed loop returns zero. These are the stations that put a number on a loop.

`B1, B1H, B2A, B3, B4, B8, B9, B13, B24, B31, B49, B52, B98, B106`

**The counting law: how many values a written rule can carry.** A programme names classes and writes a figure against each. The law counts the distinct figures, and it needs no price at all.

`B33, B43, B46, B47, B53, B55, B56, B57, B58, B102`

**Reachability, and the registration point that opens an edge.** Before any price there is whether an edge exists. These stations read the rule that opens or closes one.

`B6-A, B6-B, B15, B36, B48, B62, C1, C2, C3, E1`

**Standard price theory, recovered as special cases.** Zero data. Each station takes a published result and locates it inside the same graph object, usually as one member of a family or one value of one parameter.

`B63 to B96`

**Index numbers, and what an aggregation hides.** An index is a projection. These read the projection itself rather than the number it returns.

`B79, B81, B83, B84, B101`

**Cutting a relation, and what it rewrites.** What changes when an edge is removed or restored, read before the cut where the theorem allows that.

`B97, B103, B104, B105, B111, B115`

**Where new claims go, and how long they stay.** New money enters somewhere. These stations ask where it is a round later.

`A41, A44, A45, B112, B114, B117`

**The stratified economy: support sets, position and circulation.** The simulation track's spine. Positions are fixed before each run and every mechanism after the first is off by default.

`A0, A0b, A2, A2d, A4, A5, A6, A7, A8, A13, A14, A19, A20, A21, A26`

**Default, the subsistence floor, and the household ladder.** Where the distribution decides who stops, and the one place the track is asked to meet a measured cross-section.

`A1, A1a, A1b, A1c, A1d, A10, A11, A12, A16`

**Policy switches, and the time path rather than the closing value.** Forbearance, write-offs, levies, withdrawal, and who carries each.

`A9, A15, A17, A18, A18_B, A18_C, A18_D, A18_E, A18_F, A23, A32, A33, A37, A38, A39`
