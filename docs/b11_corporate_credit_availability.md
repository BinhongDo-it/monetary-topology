# B11 公司信用：第二域的可得性登记

2026-08-17 开。**这一份只登记数据存在什么、要多少钱、能不能下载，不设计判据。**
判据的读图另起一份，且必须写在任何数字被读之前。

## 1. 为什么是这个域，不是别的

`b8_fannie_slice.md` §15.6 的分支表，**在 B8 跑之前注册**：

| B8 结局 | 第二域 |
|---|---|
| B8-3 过 **且 B8-4b 过** | 次级车贷 ABS |
| B8-3 过，**B8-4b 不过或因 C9 不跑** | **公司信用** |
| B8-3 不过，B8-5 过 | 学贷 rehabilitation |
| 只有 B8-1 过 | 没有第二域 |

实测：**B8-3 过，B8-4b 因 C9 不跑**（§16.12），所以是第二行。
**B8-4a 不进分支表**，它是关联，拿关联挑复制域正是 §11 要防的事。

环的形状：`投资级 → 降级 → 困境交换 → 重新评级`。
**困境交换是房贷「改约」的对应物**：合同在那里被重新签一次。

## 3. 逐源，按需要归类

### 需要 1：评级历史

| 源 | 给什么 | 覆盖 | 取得 |
|---|---|---|---|
| SEC **17g-7(b)** ROCR XBRL，各 NRSRO 自己挂 | 全量评级动作，含 `RAD` 日期、`RAC` 动作码、`LEI`/`CIK`/`CUSIP`/`ISIN`，**并含 `MD` 到期、`PV` 面额、`CR` 票息** | **2012-06-15 之后**；此前的评级只作为一条 `HS` 存量记录进来 | 免费，但**SEC 不给各家 URL 的总目录** |
| `ratingshistory.info`（圣地亚哥大学法学院）把上面的 XBRL 爬成 CSV | 同上，逐机构 × 逐资产类别 | 站方称 2010 起；**实际渲染只看到 2024 之后，未核实是否滚动覆盖** | 免费，批量 CSV |
| ESMA **ERP** | 欧盟发行人逐个评级 | **2015-07-01 起**，每日 | 免费但**没有批量下载**，ESMA 自己说「无法以机器可读格式取得或以足够数量下载」 |
| ESMA **CEREP** | **只有转移矩阵与违约率的汇总** | 半年 | 免费。**对单个发行人的环无用，登记为不可用** |
| Compustat 的 S&P 评级项 | 长面板 | 1980s–2017 | **2017 年因授权停更**，且要 WRDS |

**结论：免费的评级历史从 2012 起，不是 1990s 起。** 旧的 17g-2(d)(3)
（2009 年生效）只要求**发行人付费评级的 10% 随机样本**、滞后六个月；
2015 年被 17g-7(b) 取代为全量、滞后 12/24 个月。
**没有免费的长面板，这一条不许再假设。**

### 需要 2：困境交换的标记

**S&P 年度全球公司违约与评级转移研究，Table 8**：逐个列出当年每一家公开评级的
违约主体，**带原因码明确区分 `Distressed exchange` / 漏付 / 破产**，
并带日期、国别、行业、债务余额、违约前 1 年与 3 年的评级、首次评级与日期。
**免费 PDF，需要抽取。** 已在 2018 年版上核实字段。

Moody's 年度违约研究给的是**计数与比率**；逐发行人附录**未核实存在**。
Moody's DRD（1920 起、五十万债项、带困境交换标记）是**每年 17.5 万到 28 万英镑**。

## 4. 约束在哪：一个检查决定这个域免不免费

需要 2 **免费解决且比预期好**；需要 1 免费但**只到 2012**；需要 4 部分免费。

**需要 3 是约束**，而且窄：TRACE 每一档都收费，唯一的免费出口是
openbondassetpricing 的衍生面板，**而它成不成立只挂在一件事上**：

> **那份公开 parquet 里还留着 CUSIP 吗？**
> 他们声明剥掉了专有字段（GVKEY、评级），而 CUSIP 本身是被授权的标识符。
> **留着**：可以接上 ROCR 的 `CUSIP`/`LEI`，设计在 2012–2025 上逐债项闭合。
> **不留**：需要 3 塌掉，TRACE 或 WRDS 授权变成绕不过去的。

## 5. 但在价格之前，先问环闭不闭

**B8 的教训是先数环再谈别的。** 公司信用这条环是
`投资级 → 降级 → 困境交换 → 重新评级`，而**困境交换之后重新回到投资级是罕见的**。

**所以第一个要数的不是价格，是环的数量**，而这只要需要 1 和需要 2，
两者都已经免费到手：拿 S&P Table 8 的困境交换名单，
去 ROCR 的评级历史里数**其中有多少家在交换之前是投资级、在交换之后又被重新评级**。

**若这个数只有几十，这个域就死了，与 TRACE 拿不拿得到无关。**
这一条是 C9 在本域的对应物：**一道在花任何钱之前就能过的闸。**

## 6. 2012 起点对设计的后果，现在就写

B8 的窗口判别式要**至少两个窗口**（`b1_setup.md` §7：结构性楔子在每个窗口同号）。
2012–2025 里可辨认的困境交换环境至少有三个：
**2015–2016 能源崩塌**、**2020 COVID**、**2022 之后的利率冲击**。
**三个窗口是够的**，所以 2012 起点不杀掉窗口判别式，只杀掉长面板。

**但它杀掉一件事**：B8 的六个采集季度给了跨世代复现（§13.4），
而公司信用没有「采集世代」这个轴。**跨世代复现要另找一条轴，或者不认领。**
这一条要写进读图，**不许跑完之后再补**。
