**性质：可得性件，不是预注册。** `b8_inputs_availability.md` 与 `b3_slice_availability.md` 的同族。
日期 2026-08-16。

**本件不读 B8 的任何一条预注册判据。** 它只回答两个问题：
Freddie 的 sample 能不能承载 `b8_fannie_slice.md` 已注册的那个设计，以及要不要下 Full Standard。

**上游**：`docs/b8_fannie_slice.md` §10 第 2 步（可得性检查，「it may terminate the stage」）

## 0. 先更正一条：B10 不是一个新的 slice 站

交接件 `claude/HANDOFF_B1slice_GSE逐月面板_v1.md` 提议在 GSE 逐月面板上开一个新的 B1 slice 站。
**那个位置是 B8 的。** `b8_fannie_slice.md` 的标题是 *the slice summand on a household carrier*，
§1 的四格表把 B8 定位成「agent 分层 × slice」那个空格，§2.1 的位置图是

```
current → delinquent → modified → current
```

三个顶点三条边，`b₁(G) = 3 − 3 + 1 = 1`。**赌注与交接件完全同一个，而 B8 写得更深。**

**故 B10 收缩为可得性件，不开新站。** 交接件里仍然成立、且 B8 尚未覆盖的只有一条：
**Freddie 是一个独立的 GSE 载体，vintage 铺满 1999 到 2026，而 B8 的 Fannie 只有六个季度档。**
本件量的就是这一条能不能用。

**顺带更正交接件的一处记号**：交接件写「position 图 `H`」。
`b1_theorem.md` §2 里 **`G` 是 position 图，`H` 是 agent 图**，slice cycles 是 `G` 的环。
两处字母相反，引用时以 `b1_theorem.md` 为准。

## 1. 盘上有什么

`data/raw/FreddieMac/`，28 个 `sample_YYYY.zip`，1999 到 2026，压缩合计约 1.25 GB。
每个包两个管道分隔的文本文件：`sample_orig_YYYY.txt`（31 字段）与
`sample_perf_YYYY.txt`（35 字段）。靠 loan sequence number 连（orig 第 20 列，perf 第 1 列）。

| | |
|---|---|
| 贷款数 | **1,362,490**（每 vintage 5 万笔，2025 档 49,995，2026 档 12,495 为不完整年） |
| perf 行数 | **74,937,616** |
| 每笔均月数 | 55.0（1999 档 155.2 月，2024 档 23.1 月） |

**抽样口径必须写死，它不是均匀抽样。** Freddie 的 sample 是**每个 vintage 各抽 5 万笔**，
等额分配。故 sample 上任何汇总量都是 **vintage 等权**的，不是按起息量加权的。

- **对特征搜索这是好事**：纪律 1 要求特征搜索不锚定危机，
  而等额分配恰好使 2003 那种再融资大年与 1999 那种小年同权，危机档不会因为体量大而主导。
- **但凡要外推到总体的量都必须重新加权**，权重是各 vintage 的实际起息笔数。**这一条要一起引。**

### 7·1 现在不要下 Full Standard

**四条理由，每一条独立充分：**

1. **B8 §10 第 5 步写死：`Freddie replication only if B8-1 passes`。**
   而 B8 §12 写着 *Nothing has been run. No Fannie file has been opened.*
   **B8-1 在 Fannie 上还没跑**，故 Freddie 这一臂此刻没有被授权读任何一条预测。
2. **sample 已经足够跑通 B8-0a、B8-0b、B8-1、B8-2、B8-3**，也就是 B8 §10 第 3、4 步里
   除 B8-4 之外的全部。**唯一需要全量的是 B8-4，而它排在 B8-3 之后。**
3. **量级**：全量约 5,600 万笔，sample 是 1,362,490 笔，**约 41 倍**，
   对应压缩后约 50 GB、解压后数百 GB。B7 的教训是**先量前提再花算力**，
   而本件正是那次「先量」，它的结论是前提在 B8-1 上已经成立。
4. **闸二的精神**：先问零成本时它过不过。**过了，而且是在 1.25 GB 上过的。**

### 7·2 什么时候下，与下了能买到什么

**触发条件**：B8-1 在 Fannie 上通过，且 B8-3 通过，**B8-4 成为唯一卡住的那一条**时。
那时候下的理由是具体的（Flex Mod 窗口的路径 × 类格塌到个位数），
不是「样本多一点总是好的」。

**买到什么，按 41 倍线性外推**：Flex Mod 窗口三角从 1,903 到约 **78,000**，
路径 × 类的最薄格从 15 到约 **600**。**那足以让 B8-4 在七维类网格上可读。**

**外推的限定**：41 倍是笔数比，不是三角数比。全量的 vintage 权重与 sample 不同（§1），
且全量含 sample 未抽中的贷款，修改率不必相同。**这个外推是量级估计，不是预测，
下之前不得当作已知。**

### 7·3 若要下，只下这一段就够

Freddie 按 vintage 分包（`historical_data_YYYY.zip`）。B8-4 只用 Flex Mod 窗口
（修改发生在 2017 到 2019）。**但修改年与 vintage 不是一回事**（§4），
2017–2019 的修改来自很多个 vintage，故按 vintage 剪包剪不掉多少。
**要下就是全量，没有便宜的中间档。** 这一条本身是不下的理由之一。

# 10. 追加：放款侧三字段的行为锚点，与它解开的那把锁

**加于同日，在 §1–§9 之后。** 起因是 `B8_C8-1a裁定` §7 把 **C8-1d 登记为不可跑**，理由逐字是：

> 分开需要放款侧字段（原始余额、原始利率、原始期限），且那些位置**不在 C0b 确认的锚点表里**，
> 须按 C0b 的方式**由行为挣得识别**，不得凭 layout 文档命名。

**Freddie 的 origination 文件把这三个字段单独发布，而且它们可以由行为挣得。**
一遍扫描，全部 1,362,490 笔，取每笔账龄最小的那条 perf 记录对照 orig。

## 10·1 三个字段，逐条判

| 字段 | 行为锚点 | 读数 | 判 |
|---|---|---|---|
| **原始利率**（orig 13） | 起息月 perf 当期利率（perf 11）应等于它 | **99.958% 相等到 `5e-4`** | **挣到了** |
| **原始期限**（orig 22） | 恒等式 `perf 剩余期限 + perf 账龄 = orig 原始期限` | **99.924% 精确成立** | **挣到了** |
| **原始余额**（orig 11） | 起息月 perf UPB 应等于它 | **账龄 0 的 1,192,198 笔里只有 87.86% 精确相等** | **没挣到，见 10·3** |

**首条记录账龄的分布与期限差的分布逐位对齐**，这是恒等式成立的独立旁证：

```
账龄 0  87.50%   ↔  期限精确相等  87.48%
账龄 1   8.20%   ↔  期限差 ±1     8.17%
账龄 2   1.87%       账龄 3  0.51%   账龄 4  0.23%
```

**1,040 笔（0.076%）恒等式不成立**，示例 `rem=479 age=1 origterm=360`、`rem=480 age=0 origterm=360`。
那是**首条记录之前就已经延长过期限的贷款**（30 年变 40 年），不是坏数据。**这批要单独标出，不要静默并入。**

## 10·2 这条恒等式直接打在 C8-1a 的候选一上

`B8_C8-1a裁定` §4 的第一个候选是

> **期限差一个月**：代码用 `p_rem`，真实摊还基数 `p_rem − 1`

**Freddie 上账龄 0 时 `rem = orig_term` 精确成立**，也就是首月剩余 360 期、已付 0 期。
故在 Freddie 的口径下 **`p_rem` 是对的，`p_rem − 1` 是错的**。

**限定写死**：这是 **Freddie 的口径**，C8 跑在 Fannie 上，两家的字段定义须各自确认。
**本条不裁 Fannie，它只提供一个可对照的外部读数**，而 `B8_C8-1a裁定` §4 当时只能在自己那张表里推。

## 10·3 UPB 的粒度：两个字段差一千倍，这一条要写进任何用它的地方

| 字段 | 粒度 | 读数 |
|---|---|---|
| **orig 11 原始余额** | **千元网格** | **100.000% 是 1000 的整数倍**（2007 与 2019 两档各 5 万笔，全中） |
| **perf 3 Current Actual UPB** | **到分** | 带小数分的行占 **86.74%**（2007）／**79.73%**（2019） |

## 11·2 差额的形状：它自己说出了答案

账龄 0 的 1,192,198 笔里，不等的 144,719 笔（12.139%）：

| 量 | 读数 |

## 12·1 合同月供，与为什么不能直接用原始余额算

合同月供

```
P_contract = U0 · i / (1 − (1+i)^(−n))        i = 原始利率/1200,  n = 原始期限
```

`i` 与 `n` 已由 §10·1 的行为锚点挣得（99.958% 与 99.924%）。
**`U0` 挣不得**：它 100% 落在千元网格上（§10·3），相对误差上界 `500/U0`。
20 万的贷款上是 0.25%，约合 1,100 美元月供上的 **3 美元**。
**而「借款人凑整到最近的十元」的效应也是 0 到 5 美元。两者同量级，直接用 orig `U0` 分不开这两件事。**

## 12·2 解法：从账龄 ≥ 7 的余额反解 `U0`

账龄 ≥ 7 的 UPB 到分（§11·3）。标准摊还下，余额等于剩余支付的现值：

```
U_k = U0 · [1 − (1+i)^(−(n−k))] / [1 − (1+i)^(−n)]
```

**恒等式已核**：`k = 0` 给 `U_k = U0`，`k = n` 给 `U_k = 0`。
而 `n − k` 不必由 `n` 减 `k` 得到，**它就是 perf 字段 6（剩余期限）本身**，
§10·1 那条 `剩余期限 + 账龄 = 原始期限` 正是这一步的行为锚点。于是

```
U0_hat  =  U_k · [1 − (1+i)^(−n)] / [1 − (1+i)^(−rem_k)]
```

三个输入全部精确：`i`（orig 13）、`n`（orig 22）、`rem_k`（perf 6），加一个到分的 `U_k`（perf 3, k ≥ 7）。

**这个反解自带一道闸，跑前写死**：

> **`U0_hat` 应当落在 `orig U0 ± 500` 内。**
> 落不进去的，是账龄 0 到 `k` 之间发生过额外还款（或数据问题），**整笔退出本站定义域**。
> **退出量逐 vintage 印，与读数一起。** 本节不设该比例的门槛（CLAUDE.md 11、12）。

**闸的形状合法**：它是结构性的（关于摊还恒等式，不关于世界）。

**取 `k = 7`**，第一个到分的月。

## 12·4 预设结局全部映射，三格互斥，跑前钉死

**`P_impl / P_contract` 的分布**，与 **`P_impl − P_contract` 的分布**，

## 12·9 两条臂，因为 §12.2 那道闸会自己造出第一格

**加于代码落盘之后、任何真实读数被采信之前。** 触发它的是 2019 档一次冒烟跑。

§12.2 那道闸（`U0_hat` 落在 `orig U0 ± 500`）看起来只是在验摊还恒等式，
**但它选的是「在这一段之前从来没多还过本金的贷款」**，而那恰好就是 §12.4 第一格的性状。
于是「`P_impl / P_contract` 在 1.000 上有大质量」这个读数**有一部分是闸自己造出来的**。
这是纪律 15 那条「答案被自己的构造逼出来」的一个新实例，而它藏在一道看起来纯结构性的闸里。

**闸本身不能去掉。** 固息票据多还本金**不会重新摊还**，合同月供不变、只是提前还清。
所以 `P_contract = U_k · i / (1 − (1+i)^(−rem_k))` 在多还过的贷款上会把降低了的余额
读成一个更小的合同，那个数是错的。闸是必要的。

**处置：两条臂并列跑，一起报。**

| 臂 | 参照量 | 定义域 | 性质 |
|---|---|---|---|
| **`fine_gated`** | `P_contract = U_k · i / (1 − (1+i)^(−rem_k))` | 只有过闸的段 | **利器，选择过的总体** |
| **`coarse_all`** | `P_contract = U0_orig · i / (1 − (1+i)^(−n))`，`U0_orig` 是千元网格上的原始余额 | **全部段** | **钝器（相对误差 ≤ 500/U0），未选择的总体** |

**钝到什么程度还够用**：20 万的贷款上误差约 3 美元，
**所以 `coarse_all` 读不了「恰好等于合同」，但读得了「落在整十／整百上」**，
而第二格要的正是后者。

**由此改一条读法，跑前钉死**：

> **第一格（借款人付合同月供）只在 `coarse_all` 也显出那个质量时才认。**
> `fine_gated` 单独显出它不算，那条臂的总体就是按这个性状选出来的。
> **第二格与第三格由 `coarse_all` 承载**，`fine_gated` 只作并列参考。

## 12·10 背景率的算法，写成函数不写成字面量

同一次冒烟跑抓到第二件，**它会让读数直接反号**。

「`P_min` 落在整十上」的偶然概率，第一版写的是 `1/m`，也就是模 10 给 0.1。
**那是「已知是整数美元」时的背景率。** `P_impl` 由到分的余额算出来，是**连续量**，
落在某个整十的 ±0.005 窗口内的偶然概率是

```
背景率 = 2 × 0.005 / m
```

模 10 给 **0.001**，模 100 给 **0.0001**，整数美元给 0.01。

**差一百倍，而且方向致命**：冒烟跑读到模 10 命中率 0.0066。
对着错的背景 0.1，那是**偶然的十五分之一**，读作「借款人绝不凑整」；
对着对的背景 0.001，那是**偶然的六倍多**，读作「借款人在凑整」。**同一个数，相反的结论。**

**已修**：`background_rate(m)` 写成一个把算术展开的函数，输出同时印
命中率、背景率与倍数三列。**不写字面量，因为这一行上读数会反号。**

# 13. 追加 2026-08-16：B8-4 的「不够」要重判一次，因为判它的时候交叉折还不存在

**§7 原文一字不改。** 它在当时可用的器具下是正确的裁定，本节不推翻它，只在它的触发条件前面加一步。

## 13·1 §7 判「不够」用的是哪个量

§7 的表把 B8-4 判成不够，理由是「1,903 笔，路径 × 类的格塌到个位数」。
**那句话里的量是「一格几笔」。** 它之所以是对的量，是因为当时的估计量长这样：

```
gamma(c,a) = mu(c,a) + e(c,a)  ，  Var(e) = sigma_a^2 / n(c,a)

E[S(a,a)] = E[mu(c,a)^2] + E[sigma_a^2 / n(c,a)]
                            ^^^^^^^^^^^^^^^^^^^^ 一格几笔直接进这一项
```

**格薄 → 对角虚高 → 秩读高。** 这正是 B7-4 撤稿的全部原因
（`b7_interaction_rank.md` §3.25），也正是「个位数所以不够」这句话的依据。

## 13·2 B7-16 之后那一项没了，于是要看的数换了一个

`b7_interaction_rank.md` §11：把每格的观测**交替对半分**，两折各自中心化，取

```
Stilde(a,b) = mean_c  gamma0(c,a) · gamma1(c,b)
```

两折是不相交的观测，故 `e0 ⊥ e1`，于是

```
E[Stilde(a,a)] = E[mu(c,a)^2]      对角上没有噪声项，与 n 多大无关
```

**唯一的要求是 `n(c,a) >= 2`。**

**所以 B8-4 该问的数变了：**

| | 问的是 |
| --- | --- |
| §7 当时 | 路径 × 类的格里**平均几笔** |
| **B7-16 之后** | 路径 × 类的格里**有几格达到两笔，占多少** |

**这是两个不同的数，而后一个从来没有人量过。**

## 13·3 前置步骤，写死，在下载之前

**§7·2 的触发条件（「B8-4 成为唯一卡住的那一条时就下全量」）之前插入一步：**

> **在 sample 上跑 B8-4 定义域的深度闸**：路径 × 类逐格印出格数、`n >= 2` 的格数、
> 占该格族的比例，以及落在可用格里的观测份额。**这张表决定要不要下全量，
> 而不是「个位数所以不够」这句话。**

**器具是现成的**：`experiments/b7_crossfold.py` 的 `--depth` 就是这个模板，
它什么都不估，只印深度，B8 那边照抄定义域即可。

**成本为零**：sample 的 1.25 GB 已经在盘上，`b10_freddie_availability.md` §1 量过。

## 13·4 限定，写在前面，防止把这条读成救援

**三条，每条都可能让深度闸仍然判「下全量」：**

1. **交叉折换来的是对角无偏，不是方差变小。** 1,903 笔上的估计方差照旧大。
   **它去掉的是一个会把秩读高的系统性偏倚，不是分辨率不足本身。**
2. **`n = 1` 的格整格退出定义域。** 若路径 × 类的格大多是一笔，
   可用格占比会很低，**那时候「不够」这个裁定原样成立，只是理由换了一个更准的。**
   B7 那边十九类里最薄的两类可用占比是 **0.127 与 0.251**，就是这个形态。
3. **B8-4 的统计量形状要先核过**是不是「按 (单位 × 类) 取均值再算二阶矩」。
   **是，交叉折直接适用；不是，本节不适用**，得另找办法。
   `b8_fannie_slice.md` §15 的 B8-8 已经要求先报每格观测数，**本节是那一条的下一步，不是它的替代。**
