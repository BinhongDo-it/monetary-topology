## 2. `V` 是合约现值，不是市场价格。**这一条决定整个域可不可行**

`b8_fannie_slice.md` §3.1 定的是「剩余合约义务的现值：由当前利率、当前实际余额、
剩余到期月数推出的计划付款流，在共同曲线上贴现」。
**B8 从头到尾没有读过一次市场价格。**

**B11 照抄这条口径：**

```
V = 票息流(coupon, face, maturity) 在 CMT 曲线上的现值
```

三个合同量来自 NRSRO 的 ROCR XBRL（`CR` 票息、`PV` 面额、`MD` 到期），
曲线来自 Treasury.gov，**两者都免费**。

**这不是退而求其次，是注册的那个对象。** 困境交换重写的正是票息、面额、到期，
那就是削债幅度本身；市场价格会额外带进流动性溢价与违约风险溢价，
而 §3.2 明写把那类东西折进 `ω` 是「让头条变成分析师想要的样子」的填充。

**后果**：可得性登记里被列为约束的「需要 3（价格）」**降级为非必需**，
TRACE 与 WRDS 授权都不再是阻塞。**新的约束是**：
各家 NRSRO 在公司债文件上到底填不填 `CR`/`PV`/`MD`，
**这是一个免费的检查，列为 C11-1。**

## 6. 从 B8 带过来的纪律，逐条

1. **读图写在跑之前，改判据必须双报旧读数**（R01）。
2. **底可能不是噪声。** 先问它是不是可以算出来的：一行 `np.corrcoef`（坑 45）。
3. **和为定值的分解，各项可以全错而总和照样对**（坑 46）。唯一能证伪的是
   「在某个子集上余项必须恰为零」这类恒等式。
4. **判据的通过率随分层粗细变化，它测的就是分层粗细**（坑 47）。
   按格的自由度分组看通过率，单调塌向零就是判据在测自己的难度。
5. **`abs(nan - x) > tol` 恒为 False**（坑 48）。夹具必须够大到让数值路径活起来，
   地板做成参数。
6. **夹具里两个量恒等，就没有基于该夹具的检查能分开它们**（坑 49）。
7. **粗化不是保守**（三次实例）。分层能细就细。
8. **先量再动手。** 性能猜测本轮错过一次。
9. **结构性自检抓不到东西。** 只写两种：钉在手算答案上的值，
   和错了就不可能的计数。变异只对本轮新加的承重算术跑一次。
10. **可复用的中间量一律存盘，标签是整模块源码哈希（含自身），过期即拒。**
