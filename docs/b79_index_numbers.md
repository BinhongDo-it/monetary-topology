## 0. The question this station answers

`b1_theorem.md` §2 observes that `d¹ ∘ d⁰ = 0` on a graph is elementary: a
coboundary telescopes, so it sums to zero around every cycle. That sentence has
a second life in a literature this repository had not touched. In index number
theory it is **Fisher's circular test** (Fisher 1922), and its failure is
**chain drift**, which the scanner data literature measures directly.

The question is what the enlarged graph says about that literature's standard
repair. The answer is that the repair is an object already named here.

## 1. Setup

Let the comparison points be a finite set `V`: dates, or regions, or both. A
bilateral index `P(j, k)` is a number attached to the ordered pair. Put

```
omega(j, k) = log P(j, k)
```

on the edges of the **comparison graph** `Λ = (V, E)`, one edge for each pair
actually computed. `omega` is antisymmetric exactly when the index passes the
**time reversal test** `P(j,k) P(k,j) = 1`. Fisher and Törnqvist pass it;
Laspeyres does not.

This is the enlarged graph of `b1_setup.md` with one class and the comparison
points as positions, so every result there applies verbatim.

## 2. Theorem 24

**(1) The circular test is exactness.** A system of bilateral indexes is
transitive, meaning `P(j,k) = P(j,l) P(l,k)` for all triples, if and only if
`omega = d⁰psi` for some `psi: V -> R`, if and only if every cycle of `Λ` sums
to zero. This is Theorem 1 read on `Λ`. The potential `psi` is the log of a
price level, fixed up to one additive constant per component, which is the
choice of base.

**(2) GEKS is the orthogonal projection onto the exact subspace.** On the
complete graph the least squares problem

```
min over psi of   sum over j<k  [ omega(j,k) - (psi(k) - psi(j)) ]^2
```

has normal equations whose solution, in the gauge `sum psi = 0`, is
`psi(k) = (1/n) sum over l of omega(l,k)`. Hence

```
psi(k) - psi(j) = (1/n) sum over l of [ omega(l,k) - omega(l,j) ]
                = (1/n) sum over l of [ omega(j,l) + omega(l,k) ]
```

by antisymmetry, and exponentiating gives

```
exp( psi(k) - psi(j) ) = product over l of [ P(j,l) P(l,k) ]^(1/n)
```

which is the GEKS index exactly as published (Ivancic, Diewert and Fox 2011,
eq. 5, with `n = T+1` comparison points). **So the standard transitive index is
the coboundary nearest the data, and what it discards is the non-exact part.**

Antisymmetry is load-bearing. Built on an index that fails time reversal the
same formula is not a projection, because `omega` is then not a 1-cochain.

**(3) A drift is a path, `rho` is the whole residual.** The discarded part is
`omega - d⁰psi`. Its norm is `rho(omega) = dist(omega, im d⁰)` of Theorem 5. A
chain drift is the sum of `omega` along one closed walk, so it is one linear
reading of that residual and it changes when the chain changes; `rho` does not
depend on a path. The number of independent readings is `b₁(Λ) = |E| - |V| + 1`,
which on the complete graph is `(n-1)(n-2)/2`.

**(4) A rolling window is a different projection, not the same one on less
data.** Restricting to a subgraph changes which loops are in the cycle space, so
it changes both `b₁` and the fitted coboundary. Nothing is approximated; a
different object is computed.

**(5) Space and time at once is a product graph, and its genuinely joint part
has a closed form.** Comparing `R` regions over `T` periods draws a vertex for
each pair and an edge for each single-coordinate move, so `Λ = G □ H` and
Theorem 2 applies: the cycle space is generated by slice cycles (one region over
time), agent cycles (one period across regions) and squares. Counting,

```
b₁(G □ H)        = |V_H||E_G| + |V_G||E_H| - |V_G||V_H| + 1
slice dimension  = |V_H| b₁(G)
agent dimension  = |V_G| b₁(H)
square dimension = b₁(G □ H) - slice - agent = (|V_G| - 1)(|V_H| - 1)
```

**The square part depends on the two vertex counts alone.** Computing more
bilateral comparisons raises `b₁` and raises the slice and agent parts; it does
not move the square part by one. A non-zero square is the statement that
deflating one region's series by its own price index and converting once gives a
different answer from converting at each date, which is a two-index fact and not
a defect of either index alone.

## 3. Placement

**Against the scalar price field.** That account puts one potential on positions
and predicts every cycle at zero, which here is the assertion that a transitive
system of indexes exists exactly. Chain drift is a measured non-zero. **This is
an old reading on this side and is not counted again.**

**Against index number theory.** The projection statement is theirs: the least
squares derivation of the GEKS parities is the usual one (Diewert and Fox 2017,
citing Balk 1996 and Diewert 1999), and the circular test is Fisher's. **A, and
recorded as a win on the framework's own scoring, not as a debt.** What is added
is on the counting side, and that literature does not ask for it: the dimension
of the space of independent intransitivities, the fact that `rho` is a single
path-free number where a drift is not, and the slice-agent-square split of a
space-and-time comparison with the square part at `(T-1)(R-1)`. **D.**

**C is empty, and this station cannot produce it**: it reads no data, so no
point prediction of any other account is scored here.

## 4. Related work

Fisher (1922) states the circular test and shows his ideal index fails it.
Éltető and Köves (1964) and Szulc (1964) give the transitive index that carries
their initials; Gini (1931) has the same construction earlier. Ivancic, Diewert
and Fox (2011) bring it to scanner data and to the time domain. Diewert (2021)
tabulates chain drift on a four period example. Diewert and Fox (2017) describe
the least squares derivation as the usual one. The discrete Hodge decomposition
of a 1-cochain on a graph, used to rank items from inconsistent pairwise
comparisons, is HodgeRank (Jiang, Lim, Yao and Ye 2011). Imrich and Klavžar,
*Product Graphs*, give the generating set used in (5).

## 6. Scope

One class throughout: the comparison graph here carries a single field, so `rho`
and `b₁` are read on `Λ` and the class direction of the enlarged graph is used
only in (5), where the second factor is regions rather than agent classes.
Nothing here recommends an index formula, and nothing here says which bilateral
index a statistical office should use. Nothing here measures a price, a drift or
a parity in any economy: the two numerical inputs are a published table and a
published formula. Whether a transitive index should be preferred to a chained
one is a question about which loss to minimise, and this station only identifies
the loss that GEKS minimises.
