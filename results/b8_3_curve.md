# B8-3 under the second curve construction (O36)

Generated by `experiments/b8_3_curve.py`.

**B8-3 is the headline** (§15.7) and it is the one criterion that was never re-run under an alternative construction. O33 exempted it on the ground that its `delta/floor` was two to four orders above the curve spread. **O36 found that comparison used a mislabelled denominator**: `b8_cmt_sensitivity.FLOOR` holds the `(i-b)` residual, which §6.2.11.4 itself measures at 172 to 2,343 times the floor. Against the matched-window floor the curve spread is 1,773 to 358,532, **the same order as `delta/floor`**, so the exemption is void and this is the measurement that replaces it.

Registered **`linear_in_tenor` / `cap`** against the far corner **`linear_in_log_tenor` / `linear_in_log_tenor`**, both choices changed at once.

**The argument being tested is about differencing, not magnitude.** A curve change shifts every loop; B8-3's statistic is a difference between two path populations inside one cell, and a shift common to both cancels. That was asserted and is now measured.
